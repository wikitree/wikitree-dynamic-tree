Update, version 2026.10.11-7. Thank you to everyone who has tested Genealogy Report. This update comes from a tester's careful notes on a profile with a long list of sources:

  • "Sources" heading for every ancestor. Some ancestors had their numbered sources with no "Sources" heading above them. The report now puts its own heading above the sources for every ancestor who has any.
  • "See also" after the sources. On a profile, a "See also" list (a Find a Grave memorial, for example) comes after the numbered citations. The report was showing it before them. It now follows the numbered sources, as on WikiTree.
  • Fan Chart link. The report's fan chart shows exactly the generations you chose, but the Fan Chart app that the link opens always starts with five generations, and it has no setting to change that. The link now says so.

The notes also showed that a tree with pedigree collapse (the same great-grandparents on both sides) reports correctly. The earlier updates for the title page, the links in the PDF and the Index of Locations (one heading for each country, in alphabetical order) are in this version too.

One thing that is not mine to change: on some profiles a paragraph that is indented in the biography shows in the report as a bullet. The profile's own formatting does that (WikiTree turns an indented line into a list), so the report keeps it as it is.

If you tried an earlier version, please hard-refresh the app. The version is shown at the foot of the title page. The Space page has the full list of what the report does. Next on my list: a download of the report as an HTML file, and then possibly an OpenDocument (.odt) export.
